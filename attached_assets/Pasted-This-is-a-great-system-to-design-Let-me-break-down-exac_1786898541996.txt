The Full System Architecture

Here is exactly how to build what you described:

Step 1 — Content Scheduling: Use Buffer or Later

Both Buffer and Later connect to Instagram, Facebook, TikTok, and YouTube. You upload your content, set your posting schedule, and they post automatically at the time you choose. Buffer has a free tier and a Pro tier at around $15/month that covers all four platforms.

Claude's role here is to help you write the captions and plan the schedule. You paste the content into Buffer or Later and set the time. Once it is set up it runs automatically.

Step 2 — Analytics Pull: Use Buffer Analytics + Platform APIs

Buffer pulls basic analytics from each post. For deeper data — TikTok specifically, and YouTube — you connect directly to their analytics APIs. Both are free. Instagram and Facebook pull through Meta's Graph API.

Step 3 — Weekly Report Automation: Use Make (formerly Integromat)

Make is a workflow automation tool similar to Zapier but more powerful for this use case. You set up a workflow that:

Runs every Monday morning
Pulls the previous week's post performance from Buffer or directly from each platform API
Formats it into a clean report
Sends it to a Supabase table inside Eden Communications via a webhook
Triggers a notification inside the app

Step 4 — Display Inside Eden Communications

I build an Analytics tab inside the app that pulls from that Supabase table and displays your weekly social media performance the same way your GHL ads data already shows. You open the app, go to Analytics, and see last week's numbers for every post across every platform.
